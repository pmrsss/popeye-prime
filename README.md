# Popeye Prime · Premier projet

Première page web statique du dépôt **popeye-prime**, prête à être publiée avec GitHub Pages.

## Structure

```text
popeye-prime/
├── .nojekyll
├── README.md
├── index.html
├── outils.html
└── style.css
```

## Technologies

- HTML5
- CSS3
- Aucun framework
- Aucune dépendance

## GitHub Pages

Le site est conçu pour être publié directement depuis la racine de la branche `main`.

Dans GitHub : **Settings → Pages → Build and deployment → Deploy from a branch**, puis sélectionner **main** et **/(root)**.

Adresse : https://pmrsss.github.io/popeye-prime/

## Cloudflare Pages

Le même dépôt est aussi publié par Cloudflare Pages, depuis la branche `main`, sans framework ni commande de build, avec la racine du dépôt comme dossier de sortie. Chaque push sur `main` republie le site.

Adresse : https://popeye-prime.pages.dev/
